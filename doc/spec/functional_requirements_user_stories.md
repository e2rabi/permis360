## User stories: 

As a manager I want to be able to register and login
As a manager I want to create a school with a name and a city,email,phone,address and logo
As a manager I want to create an instructor with a name,email,phone,address
As a manager I want to consult and search in the instructor list
As a manager I want to update an instructor's information (status, nombre of students,car used)
As a manager I want to assign an instructor to a student
As a manager I want to consult the calendar of the school and the instructor's schedule

As a manager I want to add a student to a school 
As a manager I want to consult and search in the student list
As a manager I want to update a student's information (status, nombre of course,car used)
As a manager I want to assign a course to a student
As a manager i want to notify (whatsp) student about the session with the instructor
As a manager I want to generate reports on student progress and instructor performance
As a manager I want to consult the calendar of the school and the student's schedule
As a manager I want to schedule a session with an instructor for a student
As a manager i want to notify (whatsp) student about the payment
As a manager I want to consult the incomes of the school (payments, invoices, etc.)

As a manager I want to add a new car to the school
As a manager I want to consult and search in the car list
As a manager I want to update a car's information (status, model, license plate, mileage)
As a manager I want to assign a car to an instructor

As a student I want to register and login
As a student I want to consult and search course list
As a student I want to update my information
As a student I want to schedule a session with an instructor
As a student I want to consult the calendar of the school and the instructor's schedule)
As a student I want to receive notifications (WhatsApp) about my sessions with the instructor
As a student I want to play with a simulator of the car and code de la route

As a student I want to use multi languages
